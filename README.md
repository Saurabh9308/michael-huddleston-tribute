# Michael J. Huddleston Tribute Page

A simple and elegant tribute webpage dedicated to **Michael J. Huddleston**, the creator of the Inner Circle Trader (ICT) concepts.

## 🧭 Overview
This webpage highlights the life, philosophy, and structured learning path of Michael J. Huddleston.  
It was created as a beginner-friendly HTML & CSS project.
